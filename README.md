# Legal Document Retrieval Project

## Overview
This project implements a Legal Document Retrieval system as part of the BKAI Legal Document Retrieval competition. The system achieves an MRR@10 score of **0.47** with reranking and **0.35** without reranking.

The system consists of three main components:
- **Bi-encoder**: For generating embeddings of questions and corpus documents.
- **Elasticsearch**: For storing and retrieving embeddings using cosine similarity and BM25.
- **Cross-encoder**: For reranking retrieved results based on semantic relevance.

## Dataset
The dataset is sourced from the BKAI Legal Document Retrieval competition. It includes questions (anchors), relevant corpus segments (positives), and irrelevant corpus segments (negatives). Below is a sample of the dataset used for training the Bi-encoder:


## System Components

### 1. Bi-encoder
The Bi-encoder finetunes the pretrained model `vinai/phobert-base` using the **Triplet Loss** function. The Triplet Loss is defined as `max(0, cosine_similarity(anchor, negative) - cosine_similarity(anchor, positive) + margin)`, with a margin of 1. The goal is to bring embeddings of the anchor (question) and positive (relevant corpus) closer together while pushing the anchor and negative (irrelevant corpus) embeddings further apart.

#### Bi-encoder Architecture
- **Input**: Question (anchor), positive corpus, and negative corpus.
- **Model**: `vinai/phobert-base` is used to encode the anchor, positive, and negative texts separately.
- **Output**: Embeddings for each input.
- **Loss**: Triplet Loss to optimize the embeddings.


### 2. Elasticsearch
The embeddings generated by the Bi-encoder for the corpus documents are stored in Elasticsearch for efficient retrieval. For a given input question, the system retrieves the top 20 documents using a combination of **cosine similarity** (on embeddings) and **BM25**. The results are then fused, and the top 20 documents with the highest fusion scores are selected.

#### Elasticsearch Data Format
The corpus documents are stored in Elasticsearch with the following structure:

```json
{
  "cid": "...",
  "text": "...",
  "segmented_text": ["..."],
  "embeddings": [...]
}
```

- `cid`: ID of the document.
- `text`: Original content of the document.
- `segmented_text`: List of segmented words.
- `embeddings`: Embedding vector of the document.

### 3. Cross-encoder
The Cross-encoder finetunes the pretrained model `vinai/phobert-base` for reranking. The input consists of a concatenated question and corpus document, with a label of `1` if relevant and `0` if irrelevant. The `[CLS]` token output is passed through a linear layer, and the model is trained using **Cross-Entropy Loss**. The goal is to better understand the semantic relationship between the question and the corpus. During inference, the retrieved results from Elasticsearch are concatenated with the input question, passed through the Cross-encoder, and reranked based on the softmax score for label `1` and then the final top 10 documents with the highest rerank scores are selected.

#### Cross-encoder Dataset
```json
{
  "qid": "...",
  "question": "...",
  "cid": "...",
  "context": "...",
  "label": "..."
}
```

#### Cross-encoder Architecture
- **Input**: Concatenated question and corpus text.
- **Model**: `vinai/phobert-base` processes the concatenated input.
- **Output**: `[CLS]` token embedding passed through a linear layer.
- **Loss**: Cross-Entropy Loss for binary classification (relevant or irrelevant).


## How to Run

### Train
#### Bi-encoder
1. Navigate to the Bi-encoder training directory:
   ```bash
   cd training_biencoder
   ```
2. Run the training script:
   ```bash
   python main.py
   ```

#### Cross-encoder
1. Navigate to the Cross-encoder training directory:
   ```bash
   cd training_crossencoder
   ```
2. Run the training script:
   ```bash
   python main.py
   ```

### Ingest
1. Navigate to the predict directory:
   ```bash
   cd predict
   ```
2. Run the ingestion script:
   ```bash
   python ingest.py
   ```

### Inference
1. Navigate to the predict directory:
   ```bash
   cd predict
   ```
2. Run the inference script:
   ```bash
   python strategy.py
   ```

